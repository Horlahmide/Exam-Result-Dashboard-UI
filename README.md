# Exam Result Dashboard (HTML + CSS)

This is a simple, responsive static dashboard built using only HTML and CSS. It shows a subject list, grades in a table, and a performance summary.

How to open

1. Open `index.html` in your browser (double-click or right-click -> Open with -> Browser).
2. No server or build step required.

Files added

- `index.html` — Main dashboard markup
- `styles.css` — Styles for layout and responsiveness

Next steps / enhancements (optional)

- Add JavaScript to filter subjects or make the table interactive.
- Export printable report (print styles).
